| instructions / cues | text |
| video_url | … |

### Muscle group enum suggestion
`chest, upper_chest, lats, upper_back, lower_back, traps, front_delts, side_delts, rear_delts, biceps, triceps, forearms, quads, hamstrings, glutes, calves, adductors, abductors, abs, obliques, hip_flexors, neck, full_body`

### Notes for AI-coach integration
- `measurement` field matters most — the AI needs to know whether to prescribe "3×8 @ 60 kg", "3×30 s", or "5 km".
- Skill progressions (`progression_of`) let the coach auto-regress when a user fails (full planche → straddle).
- `environment` on equipment lets you filter exercises by "home / outdoor park / full gym" user setting.
